# Créditos de las imágenes

## `figuras/` — figuras propias

Diagramas elaborados para esta guía (ejes del IRB 140, marcos de referencia, zonas, tipos de movimiento, `Offs`/`RelTool` y trayectorias de ejemplo). Las trayectorias se calcularon con los mismos parámetros de las rutinas RAPID del README. Las cotas del robot corresponden al modelo cinemático nominal del IRB 140 y los límites articulares al modelo de RobotStudio.
